# Liturgia Diária

API que fornece as orações e leituras do dia da Santa Missa (liturgia diária).

## Documentação da API

### Versão em teste
A nova versão está aberta para testes e sugestões antes do lançamento.

- **[Documentação da Versão v3 (Beta)](docs/v3/README.md)**
- **Novidades:** Suporte a múltiplas celebrações por dia (ex.: Missa do Crisma e da Ceia do Senhor na 5ª feira Santa; memória facultativa vs. missa ferial) e leituras como array ordenado.
- **Feedback:** Caso encontre algum problema ou tenha sugestões, abra uma [Issue](https://github.com/Dancrf/liturgia-diaria/issues).
